## 🏨 Hotel Management System

A microservices-based system that streamlines customer management, room booking, billing, inventory, and notification services through scalable REST APIs.

### 🔧 Tech Stack
- **Backend**: Java, Spring Boot, Spring MVC
- **Microservices**: OpenFeign, Netflix Eureka
- **Database**: MySQL, Spring Data JPA, Hibernate
- **Tools**: Postman, Swagger

### ✨ Key Features
- Implemented RESTful APIs using Spring Boot and Spring MVC, enabling seamless communication between services using OpenFeign and Netflix Eureka for service discovery
- Designed and managed MySQL databases using Spring Data JPA and Hibernate, implementing CRUD operations and efficient data persistence
- Tested and documented APIs using Postman and Swagger, ensuring reliable endpoint functionality and integration
